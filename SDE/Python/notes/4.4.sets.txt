SETS  
--------------------
- Contains only unique elements  
- Mutable  
- Unordered (no guaranteed order)  
- Non-indexable (can’t access by index)  

Syntax:
    s = set()
    myset = {9, 8, 7, 5}
    myset = set([1, 2, 3])   # list → set  

- Automatically deletes duplicates  
- If duplicates are added, they get removed automatically  

--------------------
Basic Operations  
- set.add(11) → adds a single element  
- set.remove(11) → removes element (KeyError if not present)  
- set.update({values}) → adds multiple elements (performs union-like update)  

--------------------
Set Operations  
- Union → s1.union(s2)  or  s1 | s2  
- Intersection → s1.intersection(s2)  or  s1 & s2  
- Difference → s1.difference(s2)  or  s1 - s2  
    (elements present only in s1)  
- Symmetric Difference → s1.symmetric_difference(s2)  
    (Union – Intersection)  

--------------------
Remove duplicates from a list  
    l = [1, 2, 2, 3, 3]  
    s1 = set(l)  
    l = list(s1)   # back to list
