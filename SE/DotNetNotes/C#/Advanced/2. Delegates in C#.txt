Delegates in C#

---------------------------------
Definition:
- A delegate is an object that knows how to call a method or a group of methods.
- It is a reference to a function.
- Delegates are type-safe function pointers.

---------------------------------
Need for Delegates:
- Useful in designing extensible and flexible applications.
- Enables passing methods as arguments to other methods.
- Supports callback mechanisms.
- Allows event handling.

---------------------------------
Multicast Delegate:
- A delegate that can point to and call multiple methods.
- When invoked, all methods in the invocation list are called in order.
- If the return type is non-void, only the result of the last method is returned.

Example:
```csharp
public delegate void MyDelegate();

public class Program
{
    static void Method1() => Console.WriteLine("Method 1 called");
    static void Method2() => Console.WriteLine("Method 2 called");

    public static void Main()
    {
        MyDelegate del = Method1;
        del += Method2; // Multicast delegate

        del(); // Calls Method1 and then Method2
    }
}
Default Delegates in C#
-------------------------------------
Func<> Delegate

Predefined generic delegate.

Can take up to 16 input parameters and must return a value.

Last type parameter specifies the return type.

-------------------------------
Action<> Delegate

Predefined generic delegate.

Can take up to 16 input parameters but does not return any value.
