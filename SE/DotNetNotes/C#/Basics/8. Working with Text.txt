# Working with Text

## String Methods
- `ToLower()` → Converts string to lowercase.
- `ToUpper()` → Converts string to uppercase.
- `Trim()` → Removes whitespace from the start and end of the string.

## Searching
- `IndexOf("value")` → First occurrence index.
- `LastIndexOf("value")` → Last occurrence index.

## Substring
- `Substring(startIndex, length)` → Returns part of a string.

## Splitting
- `Split(' ')` → Returns an array of strings split by space (or any specified delimiter).
