------------------------------
AZURE APP SERVICE - GENERAL SETTINGS & CUSTOM DOMAIN
------------------------------

GENERAL SETTINGS:

- **Environment Variables**:
  - Use App Settings to store secrets and configuration like:
    - Database connection strings
    - API keys
    - Feature flags

- These environment variables:
  - Are available at runtime inside the application
  - Can be unique for each **deployment slot** (e.g., staging slot can use staging DB)

------------------------------
CUSTOM DOMAIN SETUP FOR APP SERVICE
------------------------------

By default:
- App runs at a domain like `yourapp.azurewebsites.net`

To use your own domain:

1. Go to your Web App → **Settings → Custom Domains**

2. You can:
   - Buy a custom domain directly from **Azure**
   - Or link a domain purchased from another provider

3. Steps to link external domain:
   - Add **CNAME** or **A Record** in your domain provider's DNS settings
   - Verify ownership through Azure portal
   - Bind the domain to your app

⚠️ Tip:
- For HTTPS (SSL/TLS), enable **TLS/SSL binding** and attach a certificate
- Azure also provides **Free App Service Managed Certificates**
